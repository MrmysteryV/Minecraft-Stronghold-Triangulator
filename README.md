# Minecraft-Stronghold-Triangulator
A simple website where you input the coordinates and eye angle of at least 2 eyes of ender and it will estimate the location of the nearest stronghold.<br>This was designed so you can more easily find the stronghold without needing to be extremely accurate or installing any extra software like ninjabrain (speedrunning standard)

Link to website: https://mrmysteryv.github.io/Minecraft-Stronghold-Triangulator

## How to use

1. Put your X and Z coordinates from the f3 menu into the input fields
<img width="500" height="250" alt="image" src="https://github.com/user-attachments/assets/dbcbd8c8-f4ae-4280-9219-7a893402ca3f" />

2. Throw the eye with the f3 menu still open, focus your crosshair onto the centre of the eye (the closer the better) and record the first angle in the "Facing:" row.
<img width="500" height="250" alt="image" src="https://github.com/user-attachments/assets/7c3e93b2-2ee8-498b-956e-eaf0f187aead" />

3. Add the entry and repeat at least once more (3 or more is ideal for more accurate predictions) and go to the coordinates calculated at the bottom.
